# OpsFlow 前端交互原型

用浏览器打开[index.html](index.html)，无需安装依赖。通过导航切换“我的工单”和“服务工作台”，点击工单标题查看详情。

## 设计取舍

- 普通用户先看到需要补充信息的工单，创建入口固定在标题旁。
- 客服先看到临近时限与已经超时的任务，列表直接呈现状态和时限。
- 详情以问题、交流与回复为主体，处理信息及SLA放在侧栏；手机变为单列。
- 白色内容面板、浅灰背景、青绿色主操作。红色和琥珀色仅表达异常与时限风险。
- AI默认折叠，草稿填入输入框后仍需人工发送；解决与关闭先确认。

## 验证记录

2026-09-10，Chrome桌面1440×960与移动设备模拟390×844分别通过14项浏览器检查。刷新页面后，在控制台执行`await runPrototypeChecks()`可复现；检查会修改内存中的示例，刷新恢复。

覆盖列表与紧急筛选、空结果恢复、用户视角、待补充排序、键盘跳过导航、角色操作入口、AI草稿不自动发送、回复纯文本、接单、解决确认及取消、创建示例、横向溢出检查。截图另经目视检查。

这些是原型交互检查，不是Vue组件测试、真实设备测试或真实后端验收。身份切换不提供安全隔离；回复、时限、附件与交流记录均为演示，示例数据不持久化。
